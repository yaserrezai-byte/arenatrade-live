# 🚀 سیستم چند-ایجنته سیگنال‌دهی فیوچرز ارز دیجیتال و کپی‌تریدر هوشمند

این پروژه یک پلتفرم ماژولار **Multi-Agent (چند-ایجنته)** برای تحلیل بازار فیوچرز ارزهای دیجیتال، کپی‌تریدینگ هوشمند از نهنگ‌های برتر با **مکانیزم تعویض خودکار پس از ۲ اشتباه متوالی**، و ارسال خودکار سیگنال به **کانال تلگرام** به همراه **داشبورد مانیتورینگ زنده وب** است.

---

## 🧩 معماری ایجنت‌های تخصصی (`agents/`)

سیستم به **۱۰ ایجنت مجزا** دسته‌بندی شده است که ۸ ایجنت تحلیلی به صورت موازی (`asyncio.gather`) اجرا می‌شوند و خروجی آن‌ها توسط ایجنت سرتیم ترکیب و مدیریت ریسک می‌شود:

1. **`PriceActionAgent` (`agents/price_action_agent.py`) — ایجنت تحلیل قیمت و پرایس اکشن**
   - تشخیص الگوهای کندلی (Bullish/Bearish Engulfing، Pin Bar، چکش و ستاره ثاقب)
   - شناسایی شکاف ارزش منصفانه (**FVG / Imbalance**) و جمع‌آوری نقدینگی سقف و کف (**Liquidity Sweep / Stop Hunt**)
   - محاسبه نوسان واقعی بازار (**ATR-14**) برای تنظیم پویا فاصله حد ضرر و اهرم

2. **`MoneyFlowAgent` (`agents/money_flow_agent.py`) — ایجنت روند جریان پول و مشتقات فیوچرز**
   - تجمیع زنده **Open Interest** دلاری و **Funding Rate** در صرافی‌های متمرکز (OKX / Bitget) + **Hyperliquid**
   - تشخیص پتانسیل **Short Squeeze** یا ازدحام خطرناک لانگ‌ها
   - محاسبه جریان سفارشات تهاجمی (**CVD Delta**)، شاخص جریان پول (**MFI-14**)، فاصله از **VWAP نهادی** و عدم تقارن دیوارهای اردربوک زنده (**L2 Orderbook Imbalance**)

3. **`TechnicalIndicatorAgent` (`agents/indicator_agent.py`) — ایجنت اندیکاتورها و واگرایی‌ها**
   - محاسبه دقیق **RSI-14** + تشخیص خودکار **واگرایی مثبت و منفی (RSI Divergence)**
   - **MACD (12, 26, 9)**، **Stochastic RSI**، باندهای **Bollinger (%B & Squeeze)** و ابر **Ichimoku (Tenkan/Kijun/Kumo)**

4. **`TrendDetectionAgent` (`agents/trend_agent.py`) — ایجنت تشخیص روند و ساختار بازار**
   - تحلیل مولتی‌تایم‌فریم (`15m` + `1h` + `4h`) با روبان میانگین‌های متحرک (`EMA 9, 21, 50, 200`)
   - سنجش قدرت روند با **ADX + DI+/DI-** (فیلتر کردن بازارهای رنج و فرسایشی)
   - جهت اندیکاتور **Supertrend** و تشخیص ساختار بازار (**HH/HL** صعودی، **LH/LL** نزولی و شکست ساختار **BOS/CHoCH**)

5. **`SupportResistanceAgent` (`agents/sr_agent.py`) — ایجنت بررسی حمایت‌ها و مقاومت‌ها**
   - خوشه‌بندی پیوت‌های ماژور و مینور در تایم‌فریم جاری و بالاتر
   - سطوح اصلاحی **فیبوناچی (`0.382`, `0.5`, `0.618`)** و گره پرحجم معاملاتی (**Volume Profile POC**)
   - دیوارهای نقدینگی خرید و فروش در اردربوک زنده و جلوگیری از صدور سیگنال لانگ زیر مقاومت سنگین (و برعکس)

6. **`FundamentalAgent` (`agents/fundamental_agent.py`) — ایجنت فاندامنتال و کلان**
   - بررسی زنده **دامیننس بیت‌کوین و اتریوم**، شاخص **ترس و طمع (Fear & Greed)**، گردش نقدینگی ۲۴ ساعته (`Volume/MCap`) و ریسک تورم توکن (`FDV/MCap`) از CoinGecko

7. **`NewsSentimentAgent` (`agents/news_agent.py`) — ایجنت رصد و تحلیل اخبار**
   - دریافت لحظه‌ای فید خبری منابع معتبر جهانی (CoinTelegraph, CoinDesk, Decrypt)
   - امتیازدهی هیبریدی (لغت‌نامه مالی کریپتو + تحلیل عمیق معنایی LLM در صورت اتصال کلید هوش مصنوعی) + **فیلتر توقف اضطراری (Veto)** هنگام اخبار هک یا دی‌لیست شدن

8. **`CopyTraderAgent` (`agents/copy_trader_agent.py`) — ایجنت کپی‌تریدر هوشمند با قانون ۲ خطا**
   - اتصال مستقیم به لیدربورد زنده **Hyperliquid** (بیش از ۴۸,۰۰۰ تریدر فیوچرز) بدون نیاز به کلید خصوصی
   - رتبه‌بندی و انتخاب لیستی از موفق‌ترین نهنگ‌ها بر اساس سود ماهانه، هفتگی، سرمایه حساب و نرخ برد واقعی (`userFills`)
   - کپی و پایش پوزیشن‌های باز تریدر فعال شماره ۱ (`clearinghouseState`)
   - **ماشین وضعیت ۲ اشتباه متوالی**:
     - هر معامله بسته‌شده با سود ⬅️ شمارنده خطا ریست می‌شود (`0 / 2`)
     - اولین معامله با ضرر ⬅️ وضعیت هشدار (`1 / 2`)
     - دومین ضرر متوالی (`2 / 2`) ⬅️ تریدر فعلی به صورت خودکار به وضعیت `ROTATED_OUT` منتقل شده، نفر بعدی از صف انتظار (`STANDBY`) جایگزین می‌شود و هشدار تعویض تریدر به کانال تلگرام ارسال می‌گردد!

9. **`OrchestratorAgent` (`agents/orchestrator_agent.py`) — ایجنت سرتیم و مدیر ریسک فیوچرز**
   - ترکیب وزن‌دار گزارش هر ۸ ایجنت، محاسبه دقیق محدوده ورود (`Entry Zone`)، حد ضرر مبتنی بر حمایت/مقاومت و ATR (`Stop Loss`)، سه تارگت (`TP1, TP2, TP3`)، نسبت ریسک به ریوارد (`R:R`) و اهرم ایمن پیشنهادی (`Isolated Leverage`)

10. **`TelegramNotifierAgent` (`agents/telegram_agent.py`) — ایجنت ارسال به کانال تلگرام**
    - قالب‌بندی حرفه‌ای پیام‌های سیگنال فارسی (`HTML`) و ارسال خودکار یا دستی به کانال تلگرام + ذخیره لاگ پیش‌نمایش

---

## ⚙️ راهنمای اتصال به کانال تلگرام

1. در تلگرام به `@BotFather` پیام دهید و با دستور `/newbot` یک ربات بسازید و **Bot Token** را دریافت کنید.
2. ربات ساخته‌شده را در **کانال تلگرام** خود به عنوان **Administrator** (با دسترسی Post Messages) اضافه کنید.
3. آیدی کانال (مثلاً `@my_channel_name` برای کانال عمومی یا آیدی عددی `-1001234567890` برای کانال خصوصی) و توکن ربات را در تب **«⚙️ تنظیمات»** داشبورد وب یا در فایل `.env` وارد کرده و دکمه **«ذخیره و ارسال پیام تست»** را بزنید.

## ▶️ نحوه اجرا

### ۱. اجرای کامل (داشبورد وب زنده + اسکنر خودکار پس‌زمینه)
```bash
pip install -r requirements.txt
python main.py
```
سپس داشبورد روی پورت `8000` در دسترس است.

### ۲. اجرا روی سرور مجازی (VPS) با Docker
```bash
docker compose up -d --build
```

### ۳. اجرا در حالت خط فرمان (CLI)
```bash
# تحلیل کامل یک ارز خاص با هر ۸ ایجنت
python main.py --cli BTC

# اسکن یک‌باره کل واچ‌لیست
python main.py --scan-once
```
